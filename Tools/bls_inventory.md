## How the loader finds a shader

`CGxDevice::IShaderLoad` (`Engine/Source/Gx/CGxDevice/CGxDevice.cpp`) builds
`"%s\\%s\\%s.bls"` from the path, the profile name for the current caps, and the shader name,
then accepts the file only if the magic reads as `'GXSH'` **and** the version is exactly
`0x10003`. Otherwise it steps down one profile and tries again.

So two things have to line up: the path must resolve inside the archive, and the container
version must be the accepted one.
